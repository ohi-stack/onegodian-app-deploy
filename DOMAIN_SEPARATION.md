# OneGodian App Deployment Domain Separation — RETIRED

This repository no longer owns an active domain.

`app.onegodian.com` is retired and deleted.

The current domain contract is:

- `OneGodian.org` — organization/public identity
- `OneGodian.com` — store/commerce
- `u.OneGodian.com` — education
- `galaxy.OneGodian.com` — Galaxy
- `ODeFi.OneGodian.com` — finance/capital
- `OMOS.OneGodian.com` — protocol/developer
- `api.OneGodian.org` — shared platform core

Cross-property integration uses the API core, connectors/adapters, plugins, registries, events, and the OneGodian MCP Gateway™. Legacy App-vs-Console deployment rules in this repository are historical only.
