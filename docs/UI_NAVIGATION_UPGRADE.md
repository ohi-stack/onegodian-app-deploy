# OneGodian Navigation & UI Upgrade

## Purpose

This document defines the current OneGodian navigation and user interface standard for `app.onegodian.com` and connected OneGodian ecosystem surfaces.

The navigation standard is now a **7-main-page mega menu model**. Each main page may contain up to **6 columns of links**. This keeps the ecosystem broad enough to explain the whole platform while reducing top-level clutter.

The App is the public/member-facing product surface. It should feel clear, premium, fast, mobile-first, and connected to the entire ecosystem without exposing internal operator controls.

---

## Primary Navigation Standard

Use exactly **7 main navigation pages**:

1. Home
2. About
3. Ecosystem
4. Membership
5. Learn
6. Shop
7. Support

Each main page may support a mega menu with up to **6 columns**.

# Route Ownership

## App Surface

Allowed:

- Member dashboards
- Product access
- Certificates
- Registry viewer
- OMOS viewer
- Capital notice viewer
- Learning overview
- Media gallery
- Tools launcher

## Console Surface

Not allowed inside App:

- ACC execution controls
- deployment controls
- operator approvals
- private logs
- adapter administration
- policy mutation
- kill-switch controls

# Production Acceptance Checklist

- Navigation renders as 7 main pages.
- Each main page supports up to 6 mega menu columns.
- Desktop mega menu is readable and keyboard accessible.
- Mobile bottom navigation works.
- More menu exposes all 7 main pages.
- All menu links resolve.
- All top-level routes compile.
- Dashboard has real OneGodian content.
- No placeholder lorem ipsum remains.
- `/api/health` returns operational status.
- `/api/manifest` lists routes, plugins, and connected nodes.
- `/api/tools` lists user-facing tools only.
- `/api/stats` returns safe public/member-facing stats.
- App does not expose console-only functions.
