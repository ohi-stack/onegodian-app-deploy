Persistent OneGodian global header, ONEGODIAN.COM commercial mega menu, ecosystem switcher, commercial district registry, and 4-column footer.

== Description ==

OneGodian Global Navigation provides a production navigation layer for ONEGODIAN.COM and connected OneGodian ecosystem sites.

Core output:

* 7 primary commercial districts.
* 6 mega-menu columns per district.
* 42 total mega-menu groups.
* ODIN commercial district codes.
* 4-column footer.
* Mobile collapsible navigation.
* Ecosystem switcher.
* Sticky global header.
* Production ZIP build target: onegodian-global-navigation-v1.0.0.zip.

== Installation ==

1. Upload the plugin folder to wp-content/plugins/.
2. Activate OneGodian Global Navigation.
3. Place [onegodian_global_header] in the desired header template, reusable block, or page builder global section.
4. Place [onegodian_footer_menu] in the footer template or reusable footer section.
